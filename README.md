# ExamFlow

Obsidian 本地题库与考试插件，保留首页、题库、组卷、考试、错题和试卷历史。已移除资料目录、知识点管理、复习计划及统计页面。题库与普通考试离线可用，AI 出题及辅助评分使用用户配置的兼容模型服务。

## 安装与更新

将构建后的 `main.js`、`manifest.json`、`styles.css` 放入 vault 的 `.obsidian/plugins/ExamFlow/`，重载插件或重启 Obsidian。无需安装 PDF 引擎和资料索引资源。

首次加载新版会在备份后将旧科目题库转换为精简分片；旧试卷与答卷快照继续兼容，不自动改写。已有插件配置与源资料目录不删除。

## 题库

真题按“年份＋上/下半年＋科目”保存，例如：

```text
50@考试/ExamFlow/banks/
  index.json
  2026上-综合知识.json
  2026下-综合知识.json
  2026上-案例分析.json
  AI-综合知识.json
```

未知年份或批次明确标为未知，不猜测；AI 与其他来源单独分组。空分组不生成文件。`index.json` 保存题库身份与活动文件目录。

精简文件 `schemaVersion=2`，考试、科目、常用题型、共享来源和标签集中在文件层。题目通常只保留 ID、题干、选项、答案、解析和来源题号/页码；默认分值、默认审核状态、空关联数组及逐题时间戳不重复保存，非默认业务值仍保留。AI 补答/解析的最小标记也保留，相同标记只在文件层保存一次。完整旧格式与原解析审计保存在迁移备份及原导入过程目录中。

列表支持科目、年份和题干/标签搜索，每题紧凑显示题干以及编辑、删除、高级字段三个入口。编辑就地展开；删除题库题目不影响已经生成的试卷快照。高级字段只展示常用可编辑业务字段。

可导入旧完整 v1 JSON 和新版单个精简 v2 文件。导出 JSON 仍使用完整 v1 契约，便于兼容旧工具。手动 Codex CLI 导入使用个人技能 `$examflow-import`，其脚本已兼容新分片存储；不要直接创建旧的 `banks/<subjectId>.json`，新版索引不会使用这种额外文件。

## 组卷与历史

- 真题：只从所选科目及批次的已审核真题抽取，题量不足明确报缺口，不调用 AI。
- AI 出题：按科目和用户要求创作新题，预览确认采用后生成试卷，来源明确标为 AI。
- 真题+AI：按总题量及其中 AI 数量分别满足配额，两类题均至少一题；不以旧 AI 题冒充本次新出题。

科目默认题型为综合知识单选、案例分析简答、论文科目论文；旧案例题仍能兼容为简答作答。每次生成独立试卷并立即保存历史，即使暂不开始答题也保留。试卷包含完整题目快照。

在历史中查看试卷、开始作答、查看已有答卷或删除。删除前展示关联答卷数量并确认，先备份再删除试卷及关联答卷；有进行中答卷时拒绝删除，须先交卷或放弃。主观题支持参考评分和人工确认，AI 评分仅供参考。

## 数据与恢复

数据根默认 `50@考试/ExamFlow`。题库采用备份、恢复日志和提交索引保存；分片保存中断时按日志恢复，检测到外部修改时停止并保留文件供核查。保存前完整内容在 `_backup/banks/`；历史删除备份在 `_backup/deleted-papers/`。不要把其他同步端的同时编辑当成自动合并。

原知识点与学习状态仅保留兼容，不提供管理、复习和统计功能。历史答卷答案继续锁定。设置页提供备份恢复和冲突处理。密钥默认仅会话内使用，可选设备本地明文便利存储；不写入题库、导出或备份。
